Spike-Worm-Aquarium

8 digitale Würmer aus echten spikenden Neuronen (Brian2). Die Neuronen ticken im ~0,3 ms-Takt (schnelles Hirn) — nur der Rechner braucht länger zum Rechnen. Diese ~5-Minuten-Aufnahme wiederholt sich als Schleife und wird alle 20 Min frisch neu gebacken. Kein Echtzeit-Stream, nichts gestellt. · Code auf GitHub

satt / jagenhungrig / sparenFutter-Nester

Wie lesen: Jeder Wurm trägt seine Zahl (0–7). Farbe = Form aus echter Energie (satt=orange, hungrig=blau). Strich-Punkt-Körper = seine Spur, voller Punkt = Kopf. Reißt eine Spur ab: verhungert und neu geboren.
